# Separate Asset Briefs from image-generation prompts

Asset image prompting uses two stages: one Script-grounded analysis creates a persisted Asset Brief for every selected Asset, then a compiler combines that brief with the matching art manual, current Asset facts, and any Asset Reference contracts to render the final image-generation prompt. Asset Briefs remain provider-independent and hidden from the frontend; the Asset configuration surface displays only the final prompt. Human reference declarations outrank Script facts, which outrank current Asset descriptions, bounded identity/era/profession inference, and style defaults. Briefs record their Script, template, and input revisions so retries are stable and stale analysis is invalidated explicitly rather than silently reused.
